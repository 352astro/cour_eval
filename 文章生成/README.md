# 文章生成

公众号漫评文章的模板、样式与复制工具。生成结果放在根目录的 `2026七月新番完结吐槽/`。

## 目录

| 路径 | 用途 |
| --- | --- |
| `styles.css` | 文章版式，也是复制时内联样式的来源 |
| `wechat-copy.js` | 把 `.wechat-article` 的计算样式内联并做公众号兼容改造 |
| `示例页面/模版.html` | 单部番剧的最小模板 |
| `示例页面/2026七月新番七日番评.html` | 完整版式示例 |
| `数据/2026七月新番-工作表1.csv` | 本次评价数据快照（含 QQ 号） |

## 输入与输出

- 评价数据：anime-review 管理员的「导出原表布局」或「导出评价明细」，两者都带 QQ 号；也可以使用 `数据/` 下的表格。
- 封面：`获取动漫资源/miluxing_2026_07.csv` 中的 `cover_url`。
- 头像：用 QQ 号拼接 `https://q1.qlogo.cn/g?b=qq&nk=<QQ号>&s=640`。
- 输出：根目录 `2026七月新番完结吐槽/`。每个输出 HTML 通过 `../文章生成/styles.css` 和 `../文章生成/wechat-copy.js` 引用本目录资源。

## 复制到公众号

1. 用浏览器打开 `2026七月新番完结吐槽/` 下的 HTML。
2. 点击顶部「复制到公众号」，脚本会在页面上生成兼容版内容。
3. 按 `⌘C`（Windows 为 `Ctrl+C`）复制，再粘贴到公众号编辑器。

文章使用的外链图片（米麓星封面、QQ 头像）会原样保留。
